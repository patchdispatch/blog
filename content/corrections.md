title: "Corrections"
description: "How mistakes are reported and fixed."
---

Mistakes are possible. When one is found, the post gets a dated correction note at the top that says what was wrong and what changed. Posts are never quietly edited.

To report a mistake, email [corrections@patchdispatch.dev](mailto:corrections@patchdispatch.dev) with the post's address and what you think is wrong. A link to the official source that shows it helps most.

## Corrections so far

- **22 Nov 2026**, [LiteLLM remote code execution (CVE-2026-40217)](/2026/11/litellm-cve-2026-40217/): the post was labeled "npm"; LiteLLM is a Python package. Label corrected.
- **22 Nov 2026**, [OpenSSH password bypass on musl Linux (CVE-2026-123158)](/2026/11/openssh-cve-2026-123158/): the first version did not state the affected conditions or fixed versions. Expanded from the vendor advisories.
